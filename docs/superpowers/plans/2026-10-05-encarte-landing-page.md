# Encarté Landing Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace encarte.fr's minimal home page with a landing page. It has a centered hero with a phone fan, features, a privacy and free-software band, an FAQ and a closing call to action, in French and English.

**Architecture:**
- **Pages and style:** hand-written static HTML for 4 pages (home and privacy, FR and EN), sharing one rewritten `site/style.css`. Badges show or hide from a class on `<body>`, through pure CSS.
- **Assets:** the store badges are committed as downloaded. The phone-fan screenshots are generated by `branding/render.sh` from the existing raw captures.
- **Build:** `scripts/build-site.sh` assembles and checks the site. It gains three changes: it treats `https://encarte.fr` URLs as same-origin, it copies the Open Graph images, and it checks in-page anchors.

**Tech Stack:** HTML, CSS (no JavaScript), bash, ImageMagick 7 (dev-only, in `render.sh`), headless Chrome for checks, Python 3 for the contrast check.

**Spec:** `docs/superpowers/specs/2026-10-05-encarte-landing-page-design.md`

## Global Constraints

**Site rules**
- No JavaScript. Nothing loads from another origin.
- Absolute URLs are allowed only on `https://encarte.fr` (canonical, alternates, Open Graph) and in `<a href>` links.
- Nunito is served by the site (`fonts/nunito.ttf`). Every asset uses a relative path.

**Palette**
- Brand colors: Cream `#FFF6E8`, Navy `#1D2440`, Teal `#2E8C83` (decoration only), Mustard `#F2A93B`, White `#FFFFFF`, Red `#D32F2F` (one icon square).
- Light theme:
  - links and text accents `#1F6F5C` (5.62:1 on Cream);
  - muted text `#4A5170`;
  - alternate background `#FFF0DC`.
- Dark theme:
  - page Navy, surfaces `#262E4F`;
  - links `#7FD1C7`, muted text `#C9C3B8`;
  - privacy band `#141A33`.
- Every text/background pair is at least 4.5:1, and large titles at least 3:1.

**Copy, links and legal**
- The copy is exactly as in spec §5. French at `/`, English at `/en/`.
- Store links:
  - `https://play.google.com/store/apps/details?id=io.github.vferries.encarte`
  - `https://f-droid.org/packages/io.github.vferries.encarte/`
- Legal footer:
  - publisher Vincent Ferries;
  - contact through the GitHub issue tracker;
  - host GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA (États-Unis in French);
  - "no cookies, no trackers".

**Store badges**
- The badges are never modified.
- A badge shows only while its listing is published. Both are hidden now: `<body class="play-soon fdroid-soon">`.
- When a badge shows, so does its legal line:
  - "Google Play et le logo Google Play sont des marques de Google LLC." / "Google Play and the Google Play logo are trademarks of Google LLC.";
  - "Badge F-Droid : F-Droid, CC BY-SA 3.0" / "F-Droid badge: F-Droid, CC BY-SA 3.0", linking to `https://creativecommons.org/licenses/by-sa/3.0/`.

**Repository**
- Commit directly on `main`, with no `Co-Authored-By` trailer. Stage files by name.
- Pushing is done by the controller, only after the user agrees.

## Review Focus

1. **A visitor sees a badge for a store where the app isn't available yet.** A dead link destroys trust. Pinned by the body-class mechanism and by the Task 7 check that both badges are hidden while both listings return 404.
2. **The fan breaks at 390 px.** It can overflow horizontally or show the black frame below the side screenshots. Pinned by the Task 7 screenshots at 390 px and the `align-items: flex-start` rule.
3. **Dark theme loses contrast or makes the navy icon disappear.** Pinned by the Task 7 contrast script and the dark screenshots.
4. **A later edit breaks a nav anchor**, for example by renaming `id="faq"`. Pinned by the new anchor check in `build-site.sh` (Task 2, fault injection).
5. **The own-domain exception becomes a hole.** `https://encarte.fr.evil.com/x.js` must still fail. Pinned by the Task 2 fault injection.

- [ ] **Step 3: Treat the site's own origin as same-origin**

In the external-resource loop, after the `sed` that strips `<a …>` tags and before the `grep` for URLs, add one more `sed` to the pipeline:

```bash
    sed -E 's#https://encarte\.fr(/[^"'"'"'[:space:]>]*)?(["'"'"'[:space:]>])#\2#g' |
```

The exact form may need adapting to the current pipeline. What matters is the rule: a URL is removed only when it is exactly `https://encarte.fr` or starts with `https://encarte.fr/`, and is followed by a quote, whitespace or `>`. So `https://encarte.fr.evil.com/x.js` survives, and the build fails on it. Update the loop's comment: the canonical, `hreflang` and Open Graph tags need absolute same-origin URLs.

- [ ] **Step 4: Check in-page anchors**

After the relative-link loop, add:

```bash
# Nav and FAQ links use #fragments: each one must land on an existing id, or the menu silently breaks.
bad_anchor=0
while IFS= read -r match; do
  file=${match%%:*}
  ref=${match#*:href=\"}
  path=${ref%%#*}
  fragment=${ref#*#}
  case $path in http://*|https://*) continue ;; esac
  target=$file
  if [[ -n $path ]]; then
    target="$(dirname "$file")/$path"
    [[ $target == */ || $target == */. ]] && target="${target%.}index.html"
  fi
  [[ -e $target ]] || continue   # a missing page is reported by the link check above
  grep -q "id=\"$fragment\"" "$target" || { echo "build-site: broken anchor in $file: $ref" >&2; bad_anchor=1; }
done < <(grep -roE 'href="[^"]*#[^"]+' --include='*.html' "$out")
(( bad_anchor == 0 )) || fail "broken anchors (above)"
```

- [ ] **Step 5: Verify on the current site, then with injected faults**

Run `scripts/build-site.sh`. Expected: success. The current pages have no fragment links. `ls build/site/og-*.png` shows both images.

Then, on a scratch copy (`T=$(mktemp -d)`, copy `site/`, `scripts/`, `app/src/main/res/font/nunito.ttf`, `branding/icon.svg` and the two `featureGraphic.png` files into the same relative layout, and run `bash scripts/build-site.sh` inside `$T`), inject one fault at a time into the copy's `site/index.html`:

1. `<a href="#nope">x</a>` must fail with `broken anchor in build/site/index.html: #nope`.
2. `<p id="ok"></p><a href="#ok">x</a>` must pass.
3. `<meta property="og:image" content="https://encarte.fr/og-fr.png">` must pass.
4. `<link rel="canonical" href="https://encarte.fr/">` must pass.
5. `<link rel="stylesheet" href="https://encarte.fr.evil.com/x.css">` must fail with `external resource found`.
6. `<img src="https://cdn.example.com/a.png">` must fail with `external resource found`.

Never modify the repository's real `site/` for these tests.
